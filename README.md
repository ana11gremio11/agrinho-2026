# Agrinho - Agro Forte, Futuro Sustentável 🌱

O **Agrinho** é um site institucional moderno, responsivo e interativo, focado na promoção da agricultura sustentável. O projeto foi desenvolvido como uma landing page de página única (*Single Page Application* conceitual) para apresentar os valores, serviços, produtos e um canal de contato de uma iniciativa voltada ao agronegócio consciente.

---

## 🚀 Funcionalidades

* **Navegação Suave (Smooth Scroll):** Menu de navegação que desliza suavemente até a seção desejada ao ser clicado.
* **Formulário de Contato Inteligente:** Validação de campos obrigatórios e validação de formato de e-mail via JavaScript antes do envio.
* **Interface Responsiva:** Design adaptável para dispositivos móveis (smartphones) e computadores desktop.
* **Efeitos Visuais Dinâmicos:** Animações sutis e feedbacks visuais (foco com alteração de cor) nos campos do formulário de contato.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as tecnologias fundamentais da web:

* **HTML5:** Estruturação semântica do conteúdo da página.
* **CSS3:** Estilização personalizada, layout responsivo e transições.
* **JavaScript (Vanilla):** Lógica de interatividade, manipulação do DOM e validações.

---

## 📂 Estrutura do Projeto

O repositório é composto pelos seguintes arquivos principais:

* `index.html` - O arquivo principal contendo toda a estrutura de texto e seções do site.
* `style.css` - Folha de estilo responsável pelo design visual, cores e responsividade.
* `java.js` - Script responsável pelos comportamentos dinâmicos (scroll, formulário e animações).
